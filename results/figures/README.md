# Figures for the report and slides

Generated by `python3 python/figures.py` from results/summary.json and results/benchmark.json.

| File | Shows |
|------|-------|
| change_rate.png | Fraction of voxels flagged as changed per test case, SplatDiff vs raw point-histogram baseline, both scenes (128^3). Re-param: 0.8% / 0.4% vs 2.3% / 2.8%. Colour: 0% for both. |
| precision_recall.png | Precision and recall against ground truth for move, delete, copy. SplatDiff precision 0.85 to 0.98, recall 0.99 to 1.00; raw baseline precision 0.16 to 0.57. |
| benchmark_speedup.png | Kernel time (log axis) and speedup for serial C, OpenMP (2 vCPU sandbox) and CUDA (Colab Tesla T4) at 64^3, 128^3, 256^3, biker move. CUDA reaches 108.9x at 256^3 (kernel time, excludes host-to-device copy). |
| pipeline_diagram.png | Pipeline diagram and the four step cards from the How it works page (dark theme, 2x). Regenerate with `node scripts/export_diagram.mjs` while the server runs. |
| kernel_breakdown.png | Share of time in K1 splat, K2 compare, K3 reduce at 256^3. Splatting dominates (82 to 93%). |

UI screenshots for slides are in ../screenshots/.
Note: biker move/delete flag more voxels than the raw baseline because the raw baseline misses most of
the edit (recall 0.31 to 0.39); compare with precision_recall.png, not change rate alone.
